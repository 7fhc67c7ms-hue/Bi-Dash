# BI Produção — Fotoporcelana

## Instalação

1. Baixe o instalador `BI-Producao-Fotoporcelana-<versão>-x64.exe` do release correspondente.
2. Execute o instalador no Windows.
3. Escolha a pasta de instalação, se desejar, e conclua o assistente.
4. Abra o atalho criado na área de trabalho ou no menu Iniciar.

O instalador mantém o mesmo identificador do aplicativo e pode ser instalado por cima de uma versão anterior. Feche o dashboard antes de iniciar a atualização. Os dados do sistema ficam no servidor e não são removidos pela atualização do aplicativo.

## Uso

O aplicativo abre o dashboard publicado em uma janela própria, como um programa Windows. Faça login normalmente e utilize a importação de PDFs, os indicadores, os filtros, os registros, o estoque e as exportações. As alterações confirmadas no estoque ficam disponíveis no iPhone e em outros computadores porque o backend online é a fonte oficial dos dados.

## Requisitos

O computador precisa estar conectado à internet. O aplicativo desktop mantém as funções online do sistema: autenticação, banco de dados, processamento inteligente dos PDFs e atualizações do dashboard. Se a conexão cair antes da confirmação, a operação não é considerada salva; aguarde a reconexão e confira o histórico antes de repetir.

## Versão portátil

A versão portátil `BI-Producao-Fotoporcelana-<versão>-x64.exe` pode ser executada diretamente, sem instalação. Ela também exige internet e pode ser colocada em uma pasta ou pendrive.

## Atualizações

Cada release é gerado somente depois que a URL pública definitiva do dashboard é confirmada. Não reutilize um instalador antigo para testar uma publicação nova: o endereço carregado fica embutido no executável durante a compilação.

## Observação de segurança

O instalador não possui certificado de assinatura digital comercial. O Windows pode exibir um aviso inicial do SmartScreen; nesse caso, confira se o arquivo foi baixado do local correto e selecione **Mais informações > Executar assim mesmo**.
